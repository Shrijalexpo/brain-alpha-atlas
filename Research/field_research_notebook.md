## Operating Income

Field:

```text
operating_income
```

Observed search notes:

- Main `operating_income` field appeared as Matrix.
- Alpha count mentioned: about `68,658`.
- Related search results included:

```text
fnd6_oidbps
fnd6_newa2v1300_oidbp
fnd6_ops
fnd6_oiadps
```

Interpretation:

- Prefer Matrix fields as a beginner.
- Vector fields are usually less flexible for common alpha construction.

Economic intuition:

- Measures core business profitability.
- More useful after normalizing for company size or valuation.

Tested variants:

```text
rank(ts_rank(operating_income, 12))
rank(ts_mean(operating_income, 4))
rank(ts_delta(operating_income, 4))
zscore(rank(operating_income / cap) + 0.4 * rank(-returns))
zscore(rank(operating_income / cap) + 0.4 * rank(-ts_rank(returns, 20)))
```

Conclusion:

- Raw operating income and simple variants were weak.
- Do not spend more time on raw operating income unless using a clearly different transform or denominator.

Useful denominator ideas:

```text
assets
enterprise_value
market_cap
sales
revenue
```

## Cashflow Op

Field:

```text
cashflow_op
```

Economic intuition:

- Measures cash generated by operations.
- Can be more robust than accounting earnings.

Tested base:

```text
cashflow_op / enterprise_value
```

Known result:

```text
Sharpe: 0.41
```

Conclusion:

- Positive but weak standalone.
- Use as current base signal and add one complementary factor at a time.

Potential pairings:

```text
return_equity
sales_growth
current_ratio
-debt/assets
```

## Return Equity

Field:

```text
return_equity
```

Economic intuition:

- Quality/profitability measure.
- Best used as a complement to value or cash flow yield.

Known issue:

- In large quality/value composites, adding more quality terms did not help.

Current suggested test:

```text
rank(cashflow_op / enterprise_value) + rank(return_equity)
```

Status:

- Suggested but not confirmed as simulated.

## Debt

Field:

```text
debt
```

Economic intuition:

- Leverage and balance-sheet risk.

Common transform:

```text
debt / assets
```

Known issue:

- Penalizing debt inside the nonlinear product did not help.
- Still useful as a separate balance sheet dimension in future controlled tests.

## Volume And ADV20

Fields:

```text
volume
adv20
```

Economic intuition:

- `volume / adv20` captures unusual volume.

Known issue:

- Can increase Turnover, especially with daily return signals.

Recorded alpha:

```text
zscore(rank(dividend) + 0.3 * rank(volume / adv20) + 0.2 * rank(-returns))
```

Result:

```text
Sharpe: 1.78
Fitness: 0.67
Turnover: 57.5%
```

Conclusion:

- Good signal, too much Turnover.

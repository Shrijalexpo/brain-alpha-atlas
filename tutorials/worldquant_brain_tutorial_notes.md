## Module 1 - BRAIN Platform And Quant Investing

BRAIN is a cloud-based simulation platform used to develop and test quantitative ideas called Alphas.

An Alpha is a mathematical model that seeks to predict future price movement of financial instruments.

Quantitative investing means:

- using predetermined mathematical rules,
- avoiding emotional discretionary decisions,
- testing ideas through backtesting.

The quant workflow:

```text
Idea -> Alpha Formula -> Backtest -> Metrics -> Improve or discard
```

Tutorial time limit:

- The tutorial series has a 30-day completion window.
- If not completed within the window, progress may reset.

First tutorial alpha:

```text
-returns
```

Meaning:

- `returns` is the stock's recent return.
- `-returns` bets against recent returns.
- This is price reversion or mean reversion.

## Module 2 - What Is An Alpha?

`returns` is a data field.

The minus sign in `-returns` is an operator that reverses the sign.

If a stock had high positive return yesterday, `-returns` gives it a low value.
If a stock had negative return yesterday, `-returns` gives it a high value.

This predicts:

```text
Recent winners may fall.
Recent losers may rise.
```

WorldQuant definition:

```text
Alpha = a mathematical model that seeks to predict the future price movement of various financial instruments.
```

Operators transform data fields.

Example:

```text
rank(-returns)
```

`rank()` sorts values cross-sectionally and maps them to evenly spaced values between 0 and 1.

For 4 stocks sorted low to high:

```text
Position 1 -> 0.00
Position 2 -> 0.33
Position 3 -> 0.67
Position 4 -> 1.00
```

Formula:

```text
Rank = (Position - 1) / (Total Stocks - 1)
```

## Module 3 - Performance Metrics

PnL:

- Cumulative profit and loss over the backtest.
- Smooth upward PnL is preferred.

Sharpe:

- Risk-adjusted return.
- Higher is better.
- Tutorial formula: annualized average returns divided by annualized standard deviation of returns.
- Annualization uses about `sqrt(250)`.

Turnover:

- Percentage of capital traded each day.
- Formula idea: `Value Traded / Value Held`.
- High turnover can imply high trading cost.

Fitness:

```text
Fitness = Sharpe * sqrt(abs(Returns)) / max(Turnover, 0.125)
```

Returns:

- Annualized profit generated by the alpha.
- BRAIN uses long-short portfolio assumptions.

Drawdown:

- Largest loss period in the backtest.
- Target Return/Drawdown ratio above 1 when possible.

Margin:

- PnL relative to traded amount.
- Uses basis points, not percent.

## Module 4 - What Happens During Simulation

BRAIN converts an expression into positions.

Pipeline:

```text
Expression
-> Alpha Values
-> Neutralization
-> Normalized Weights
-> Position Sizing
-> Next-Day Returns
-> PnL
-> Metrics
```

Long position:

- Buy stock.
- Profit if price rises.

Short position:

- Sell/short stock.
- Profit if price falls.

For `rank(-returns)`, alpha values may range from 0 to 1.

Market neutralization:

1. Subtract the mean from each alpha value.
2. Divide each centered value by the sum of absolute values.
3. Multiply normalized weights by book size.

Purpose:

- Remove broad market exposure.
- Create a long-short portfolio.
- Focus on relative outperformance rather than market direction.

## Module 5 - Market Neutralization And Decay

Long-only portfolios can look good simply because the market rises.

Example:

```text
rank(returns)
rank(-returns)
```

With Neutralization = None, both can show similar upward PnL because both may effectively be long-only.

Market neutralization makes the portfolio:

```text
50% long
50% short
```

Decay:

- Slows down position changes.
- Uses part of past positions in today's position.
- Reduces Turnover.
- May delay signal response.

For Decay = 3:

```text
(Position_today * 3 + Position_yesterday * 2 + Position_2_days_ago * 1) / 6
```

General idea:

```text
Decay_linear(x, n) =
(x[date] * n + x[date-1] * (n-1) + ... + x[date-n+1] * 1)
/
(n + (n-1) + ... + 1)
```

Typical Decay values are below 10.

## Module 6 - Settings

Language / Instrument Type:

- BRAIN uses Fast Expression.
- Tutorial focuses on Equity.

Region:

- Beginner access currently discussed as USA.
- Consultant-level regions may include ASI, EUR, CHN, KOR, TWN, HKG, JPN, AMR, and GLB.

Universe:

- Group of stocks by liquidity.
- Examples: TOP3000, TOP1000, TOP500, TOP200.

Delay:

- `Delay = 1`: use data available up to yesterday.
- `Delay = 0`: use same-day information, more restrictive.

Neutralization:

- Market neutralization removes broad market exposure.
- Industry/Subindustry neutralization removes group exposure within industries or subindustries.

Decay:

- Higher values reduce Turnover but may weaken current signal strength.

Truncation:

- Limits maximum single-stock weight.
- For TOP3000, around `0.01` is typical; tutorial examples may use higher values.

Pasteurization:

- Controls whether out-of-universe stocks are included in calculations or treated as NaN.

Unit Handling:

- Detects and warns about mismatched data field units.

NaN Handling:

- Determines whether missing values are replaced with 0.

Test Period:

- Hides part of PnL for validation.
- Useful for checking robustness and overfitting.

## Module 7 - Finding Data Fields

BRAIN data structure:

```text
Dataset Categories -> Datasets -> Data Fields
```

Dataset categories:

- Broad groups such as Price Volume or Fundamental data.

Datasets:

- Thematic collections of fields.
- Example: PV1 contains price/volume fields.
- Example: fundamental6 contains financial statement fields.

Data fields:

- Actual variables used in Fast Expression.
- Examples: `returns`, `volume`, `close`, `operating_income`.

Search tips:

- Set Region, Delay, and Universe before searching because availability may differ.
- Search by theme, not only by alpha count.

Suggested starter fields:

```text
close
volume
adv20
vwap
high
low
operating_income
cashflow_op
enterprise_value
return_equity
return_assets
debt
assets
sales_growth
```

Example non-returns tutorial alphas:

```text
rank(volume)
rank(volume / adv20)
rank(high - low)
rank(close - vwap)
```

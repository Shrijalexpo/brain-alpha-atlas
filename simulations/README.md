# Simulations Folder

Use this folder to store every WorldQuant BRAIN simulation result the user shares.

For each simulation, record:

```text
Date:
Expression:
Dataset/fields:
Settings:
Sharpe:
Fitness:
Turnover:
Returns:
Drawdown:
Margin:
Sub-universe Sharpe:
Weight distribution:
Warnings/errors:
Conclusion:
Next action:
```

Rules:

- Before suggesting a new alpha, check `past_simulations.md`.
- Do not repeat previously tested expressions unless the goal is a controlled settings test.
- If only a screenshot is available, transcribe the visible metrics and mark anything unclear as "unknown".
